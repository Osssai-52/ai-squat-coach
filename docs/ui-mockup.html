설계 노트

  • 렙 카운터를 우상단에 크게 — 운동 중엔 2m 밖에서 봐야 함 (글자 다 크게)
  • 피드백 배너는 최저점 판정 직후 2초 표시 + 동시에 음성 출력
  • 렙 도트: 초록=정상, 빨강=오류 — 진행 상황이 한눈에
  • 각도 숫자판은 기본 숨김, 우하단 "디버그 ⚙"로 토글 (개발·시연 설명용)
  • 목표 횟수 도달 시 자동으로 리포트 화면 전환
