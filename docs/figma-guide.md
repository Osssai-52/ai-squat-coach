# 피그마 시안 가이드 (팀 참고용)

> 목적: 발표/데모 자료용 시안 + 팀 디자인 논의 기반. 새로 디자인하는 게 아니라
> 이미 합의된 [docs/ui-mockup.html](ui-mockup.html)과 실제 구현
> [frontend/style.css](../frontend/style.css)의 값을 그대로 피그마로 옮기는 작업입니다.

## 피그마 파일 구조

- 파일 1개: `AI 스쿼트 코치`
- 페이지 3개: `Design System` / `Screens` / `Prototype`

## 1. Design System 페이지 (먼저 만들 것)

### 컬러 스타일

| 이름 | 값 | 용도 |
|---|---|---|
| page | `#0d0d0d` | 배경 |
| surface | `#1a1a19` | 카드 배경 |
| surface-2 | `#22221f` | 강조 카드 배경 |
| ink | `#ffffff` | 본문 텍스트 (밝음) |
| ink-2 | `#c3c2b7` | 본문 텍스트 (보조) |
| ink-muted | `#898781` | 라벨/캡션 |

| c-good | `#008300` | 클래스색 — 정상 |
| c-depth | `#3987e5` | 클래스색 — 깊이 부족 |
| c-back | `#c98500` | 클래스색 — 허리 굽음 |
| c-knee | `#d55181` | 클래스색 — 무릎 모임 |
| bad | `#d03b3b` | 오류 배너 |

⚠ 클래스 4색(good/depth/back/knee)은 색각이상(CVD) 검증을 거친 세트입니다. 임의로 바꾸지 말고, 바꿀 경우 팀 전체에 알리세요.

### 텍스트 스타일

| 이름 | 크기 / 굵기 | 사용처 |
|---|---|---|
| Logo | 1.8rem / 700 | 시작 화면 앱 로고 |
| Hero Number | 2.4rem / 700 | 운동 화면 렙 카운트 |
| Stat Value | 2rem / 700 | 리포트 통계 숫자 |
| Body | 0.9rem / 400 | 일반 본문 |
| Caption | 0.8rem / 400, ink-muted | 라벨/보조 텍스트 |

### 컴포넌트

- `chip` — 알약형, on/off 상태 (목표 횟수 선택)
- `btn-primary` — accent 배경, 완전 둥근 pill 버튼
- `btn-ghost` — 테두리만 있는 보조 버튼
- `stat-tile` — surface 배경 카드, label + value
- `rep-dot` — 원형 10px, good(초록)/err(빨강)/empty(회색) 3상태
- `feedback-banner` — 배너, bad(빨강)/ok(초록) 2상태

## 2. Screens 페이지 — 프레임 3개

프레임 크기: 1280×800 (데스크톱, 실제 앱 기준). 각 프레임 이름은 아래처럼 지정.

### ① 시작
- 로고 (앱 이름 + 부제)
- exercise-card (스쿼트 아이콘 + 설명)
- stance-guide (측면 스탠스 안내 SVG + 설명 텍스트)
- 목표 횟수 chip 3개 (5 / 10 / 15회, 10회 기본 선택)
- btn-primary ("운동 시작")

### ② 운동
- 카메라 영역 (스켈레톤 SVG placeholder, 검정 배경)
- 상단 중앙 feedback-banner ("더 깊이 앉으세요!")
- 우상단 rep-hud (렙 숫자 "6 / 10" + phase "올라오는 중")
- 하단 중앙 rep-dots (진행 상태 점 10개)
- 하단 중앙 btn-ghost ("운동 종료")
- 우하단 디버그 토글 텍스트

### ③ 리포트
- hero-row: stat-tile 2개 ("정상 자세 7/10회", "가장 잦은 오류: 깊이 부족 2회")
- dist-chart: 막대 차트(good/depth/back 비율) + 범례 4개(0회 포함 전부 표시)
- rep-list: 렙별 결과 리스트 (번호, 색점, 라벨, 무릎 각도)
- report-actions: btn-primary("다시 하기") + btn-ghost("결과 이미지 저장")

각 프레임에는 `ui-mockup.html`에 이미 있는 예시 데이터(7/10회, 깊이 부족 2회 등)를 그대로 채워서 발표 때 바로 스크린샷으로 쓸 수 있게 합니다.

## 3. Prototype 페이지

클릭 흐름: **① 시작 → ② 운동 → ③ 리포트**
- "운동 시작" 버튼 → ② 프레임으로 연결
- 목표 횟수 도달 지점(예: rep-dots 다 채워진 상태) → ③ 프레임으로 연결

발표 리허설 때 피그마 프레젠테이션 모드(우상단 ▶ 재생)로 클릭하면서 데모처럼 보여줄 수 있습니다.

## 4. 피그마 처음 쓰는 사람을 위한 순서

1. [figma.com](https://figma.com) 가입 (구글 계정으로, 무료 플랜으로 충분)
2. `New design file` 생성, 파일명 `AI 스쿼트 코치`로 변경
3. 사각형 그리고 채우기 색 지정 → 우클릭 `Create style`로 위 컬러 하나씩 등록
4. `F` 키 → 프레임 도구, 우측 패널에서 크기 1280×800 지정 → 이름 "① 시작" 등으로 변경
5. 텍스트(`T`)/사각형(`R`)/원(`O`) 도구로 요소 배치. 여러 요소 묶어서 `Shift+A`(오토레이아웃)로 간격 자동 정렬 추천
6. 다 만들면 상단 `Prototype` 탭 → 요소 선택 시 나오는 파란 동그라미를 드래그해서 다음 프레임에 연결
7. 우상단 `Share` 버튼 → 팀원 이메일 초대, 권한은 `Edit`로 설정
