# 오류 클래스 정의 (확정)

> **촬영 각도 확정**: 정면 기준 **45도 대각선**으로 촬영. 무릎 모임(knee valgus)·발뒤꿈치 들림 판정에
> 필요한 양 무릎/발목/뒤꿈치 가시성과, 깊이·허리 판정에 필요한 시상면(옆모습) 정보를 한 카메라로
> 동시에 확보하는 절충안. 상세는 [docs/recording-rules.md](recording-rules.md) 참고.
>
> **촬영 형식**: 정지 사진, 렙의 최저점 순간 1장씩 (영상 프레임 추출 아님).

## 클래스별 판정 기준 (최저점 프레임 기준)

| 코드 | 이름 | 어떻게 보이는가 | 관련 피처 |
|---|---|---|---|
| `good` | 정상 | 허벅지가 수평 근처까지 내려가고 허리가 곧으며 무릎이 발끝 방향 유지, 뒤꿈치가 지면에 붙어있음 | 전부 |
| `depth` | 하프스쿼트 | 최저점에서 엉덩이(무릎)가 충분히 안 내려감 (반쯤만 앉음) | knee_angle 큼 |
| `knee` | 무릎 모임 | 최저점에서 무릎이 발목보다 안쪽으로 무너짐 | knee_valgus_ratio 작음 |
| `back` | Forward Lean | 허리가 지나치게 숙여지며 엉덩이만 들리는 자세 | trunk_lean 큼, hip_angle 작음 |
| `heel` | Heel Lift | 발목 가동성 부족으로 까치발 들며 내려감 | heel_lift_ratio 큼 |

`back`(Forward Lean)에 대한 참고: "엉덩이가 상체보다 먼저 들린다"는 건 동작(시간)에 걸친
패턴인데, 지금은 렙당 최저점 사진 1장만 있어서 움직임 자체는 볼 수 없습니다. 대신 **최저점 순간에
이미 상체가 과도하게 숙여져 있는 정도(trunk_lean)** 를 정적인 대리 지표로 사용합니다. 나중에
영상 데이터가 생기면 "엉덩이 상승 속도 vs 상체 각도 변화 속도" 같은 시간 기반 피처로 정교화할 수
있습니다.

## 판정 시점

- 프레임 단위 판정이 아니라 **렙의 최저점 프레임(사진)에서만 판정**한다
- 실시간 앱에서는: 최저점 = 해당 렙에서 무릎 각도가 최소인 프레임
- 내려가는 중/올라오는 중 프레임은 판정에 사용하지 않음 (라벨링도 동일 기준)

## 피처 정의

### 무릎 모임(knee)
```
knee_valgus_ratio = |L_KNEE.x - R_KNEE.x| / |L_ANKLE.x - R_ANKLE.x|
```
무릎 사이 거리를 발목 사이 거리로 나눈 비율. 무릎이 발목보다 안쪽으로 모이면 이 값이 1보다
작아짐. 좌우 랜드마크가 둘 다 필요하므로 45도 촬영에서만 신뢰도 있게 계산 가능(순수 측면에서는
한쪽 무릎/발목이 가려져 부정확함).

### 발뒤꿈치 들림(heel)
```
heel_lift_ratio = (TOE.y - HEEL.y) / |HEEL - TOE|   (발끝-뒤꿈치 거리로 정규화)
```
발끝(foot index) 대비 뒤꿈치가 얼마나 위로 떠 있는지. 화면 좌표는 아래로 갈수록 y가 커지므로,
뒤꿈치가 들리면(위로 뜨면) 이 값이 커짐. 발 길이로 나눠서 카메라 거리·체구 차이에 무관하게 만듦.
MediaPipe 랜드마크 29/30(뒤꿈치), 31/32(발끝) 사용.

## 판정 우선순위 (규칙 기반 v0 — JS/Python 동일 순서 유지)

```
depth (knee_angle > 100) → knee (knee_valgus_ratio < 0.7) → heel (heel_lift_ratio > 0.3)
  → back (trunk_lean > 50) → good
```

heel을 back보다 먼저 보는 이유: 발목 가동성 부족(heel)이 상체 숙임(back)의 원인이 되는 경우가
많아, 근본 원인 쪽을 먼저 판정.

## 임계값 초안 (규칙 기반 v0 — 전부 추정치, 실측 데이터로 튜닝 필요)

- 하프스쿼트: 최저점 무릎 각도 > 100°
- 무릎 모임: 최저점 knee_valgus_ratio < 0.7
- 발뒤꿈치 들림: 최저점 heel_lift_ratio > 0.3
- Forward Lean: 최저점 허리 기울기 > 50°
- 서 있음 판정: 무릎 각도 ≥ 160°
