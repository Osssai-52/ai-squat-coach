# 데이터 촬영 규칙 (전원 필독)

촬영 전에 이 규칙대로 세팅을 통일하세요. 규칙이 다르면 데이터를 섞어 쓸 수 없습니다.

## 카메라 세팅

- **방향**: **45° 반측면** (정면에서 45° 비스듬히). 기존 수집 사진이 전부 45°라서 프로젝트 전체를 45°로 통일함
  — **영상·사진·발표 데모 모두 동일 각도**여야 함 (학습과 추론의 시점이 다르면 모델이 오판)
- 전원 **같은 쪽**으로 통일 (예: 카메라에서 봤을 때 왼쪽 어깨가 가까운 45°)
- **높이**: 허리~가슴 높이, 삼각대 또는 책상 위 고정
- **거리**: 전신이 프레임에 들어오고 위아래 여유 공간 확보
- **가로 촬영** (16:9)
- 배경: 최대한 단순하게, 다른 사람이 프레임에 들어오지 않게

## 촬영 단위

- 한 파일 = 한 클래스의 스쿼트 5~10회 연속
- 인당 클래스별 20~30회 목표 (파일 3~4개)
- **틀린 자세는 과장해서** 명확하게. 애매한 동작은 라벨링 분쟁만 만든다

## 파일명 규칙 (라벨 자동 추출에 사용됨 — 반드시 준수)

```
이름_클래스_회차.mp4
```

| 클래스 코드 | 의미 |
|---|---|
| `good` | 정상 |
| `depth` | 깊이 부족 (하프스쿼트) |
| `back` | 허리 굽음 (Forward Lean) |
| `heel` | 발뒤꿈치 들림 (Heel Lift) |
| `knee` | 무릎 모임 (45° 통일로 학습 포함 — 실데이터 검증 조건부) |

예: `minsu_good_01.mp4`, `jiyeon_depth_03.mp4`

## 사진 파일명 규칙 (`data/images/클래스/` 폴더에 넣을 때)

- 폴더명이 라벨이므로 파일명엔 클래스 불필요
- **팀원 촬영**: `이름_번호.jpg` (예: `minsu_01.jpg`) — 밑줄 앞 이름으로 같은 사람이
  train/test에 안 섞이게 그룹핑됨
- **웹 수집**: 밑줄 없이 고유 이름 (예: `pexels001.jpg`) — 파일 단위 그룹
