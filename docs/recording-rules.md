# 데이터 촬영 규칙 (전원 필독)

촬영 전에 이 규칙대로 세팅을 통일하세요. 규칙이 다르면 데이터를 섞어 쓸 수 없습니다.

> **촬영 형식: 정지 사진** (영상 X). 스쿼트 최저점 순간에 딱 맞춰 사진 1장을 찍습니다
> (또는 영상으로 찍고 최저점 프레임만 캡처해서 저장). `ml/extract_features.py`는
> 사진 1장 = 샘플 1개로 처리하도록 돼 있습니다.

## 카메라 세팅

- **방향**: 정면 기준 **45도 대각선**. 전원 **같은 쪽**(카메라에서 봤을 때 왼쪽 얼굴이 보이는 방향)으로 통일
  - 45도인 이유: 정면에 가까운 각도라 양 무릎·발목이 다 보여 무릎 모임(knee valgus) 판정이 가능하고,
    동시에 옆모습 정보도 남아있어 깊이·허리 판정용 각도 계산도 유지됨
  - 전신뿐 아니라 **양쪽 무릎과 발목·뒤꿈치가 카메라에 가려지지 않고 다 보이는지** 촬영 전에 확인
    (뒤꿈치 들림 판정에 필요)
- **높이**: 허리~가슴 높이, 삼각대 또는 책상 위 고정
- **거리**: 전신이 프레임에 들어오고 위아래 여유 공간 확보
- **가로 촬영** (16:9)
- 배경: 최대한 단순하게, 다른 사람이 프레임에 들어오지 않게

## 촬영 단위

- **한 장 = 한 렙의 최저점 순간 1컷**
- 인당 클래스별 20~30장 목표
- **틀린 자세는 과장해서** 명확하게. 애매한 동작은 라벨링 분쟁만 만든다

## 파일명 규칙 (라벨 자동 추출에 사용됨 — 반드시 준수)

```
이름_클래스_회차.jpg
```

| 클래스 코드 | 의미 |
|---|---|
| `good` | 정상 |
| `depth` | 하프스쿼트 (깊이 부족) |
| `knee` | 무릎 모임 |
| `back` | Forward Lean (허리 숙임 + 엉덩이 들림) |
| `heel` | Heel Lift (발뒤꿈치 들림) |

예: `minsu_good_01.jpg`, `jiyeon_depth_03.jpg`
